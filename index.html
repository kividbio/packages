KiviDB packages

apt and dnf repositories for KiviDB, the default build (no Lua, no TLS), for amd64/x86_64 and arm64/aarch64. Metadata and RPMs are signed with the key 649217DE0F7FD7DB3D7BAC3AE21D8F6EDDE5F489.

Debian and Ubuntu

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://packages.kividb.io/kividb.gpg | sudo tee /etc/apt/keyrings/kividb.gpg >/dev/null
curl -fsSL https://packages.kividb.io/kividb.sources | sudo tee /etc/apt/sources.list.d/kividb.sources >/dev/null
sudo apt update && sudo apt install kividb

Fedora, RHEL and compatibles, Amazon Linux 2023

sudo curl -fsSL -o /etc/yum.repos.d/kividb.repo https://packages.kividb.io/kividb.repo
sudo dnf install kividb

Full instructions: docs/INSTALL.md. The newest 20 versions are kept.
